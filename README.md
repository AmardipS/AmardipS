## FAQ: "Assign Copilot an issue" in Visual Studio

### Why don't I have the "Assign Copilot an issue" tool in Visual Studio?

The "Assign Copilot an issue" feature allows you to assign GitHub Issues directly to Copilot, which can then automatically generate code suggestions, create branches, and open pull requests. If you don't see this feature, check the following requirements:

#### Requirements:
1. **GitHub Copilot Subscription** - You need an active GitHub Copilot subscription (Individual, Business, or Enterprise)
2. **Visual Studio 2022 or later** - This feature requires Visual Studio 2022 or newer versions
3. **GitHub Copilot Extension** - Install and configure the GitHub Copilot extension in Visual Studio
4. **GitHub Account Authentication** - Sign in with a GitHub account that has a valid Copilot subscription
5. **Repository Permissions** - You need admin or write permissions on the repository to assign issues to Copilot

#### Note:
Visual Studio support for Copilot agent features may have partial functionality compared to VS Code or GitHub.com. For the most complete experience with the "Assign Copilot an issue" feature, consider using:
- **VS Code** with the GitHub Copilot extension
- **GitHub.com** directly through the web interface

#### Additional Setup:
- Ensure your repository has Copilot enabled in the repository settings
- Organization admins may need to enable Copilot agents for your organization
- Check that your organization's permissions allow assigning issues to Copilot
